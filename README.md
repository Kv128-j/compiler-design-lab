## Overview

This repository contains the implementation of 15 lab experiments related to Compiler Design.
All programs are written in C and demonstrate various phases of a compiler including lexical analysis, parsing, intermediate code generation, and optimization.

---

## List of Experiments

### Lab 1: Lexical Analyzer

A program to identify tokens such as keywords, identifiers, and operators from the input source code.

### Lab 2: Regular Expression to NFA

Conversion of a given regular expression into a Non-deterministic Finite Automaton using standard construction techniques.

### Lab 3: NFA to DFA

Conversion of NFA into DFA using subset construction method.

### Lab 4: Grammar Transformation

Elimination of ambiguity, left recursion, and performing left factoring on a given grammar.

### Lab 5: FIRST and FOLLOW

Computation of FIRST and FOLLOW sets for a given context-free grammar.

### Lab 6: Predictive Parsing Table

Construction of LL(1) predictive parsing table using FIRST and FOLLOW sets.

### Lab 7: Shift Reduce Parsing

Implementation of bottom-up parsing using shift-reduce method.

### Lab 8: LEADING and TRAILING

Computation of LEADING and TRAILING sets for operator precedence grammar.

### Lab 9: LR(0) Items

Construction of LR(0) item sets and canonical collection.

### Lab 10: Postfix and Prefix Conversion

Conversion of infix expressions into postfix and prefix forms.

### Lab 11: Intermediate Code Generation

Representation of expressions using Quadruple, Triple, and Indirect Triple methods.

### Lab 12: Simple Code Generator

Generation of simple target code from intermediate representation.

### Lab 13: Directed Acyclic Graph (DAG)

Representation of expressions using DAG for optimization.

### Lab 14: Global Data Flow Analysis

Analysis of data dependencies and flow of information in a program.

### Lab 15: Storage Allocation (Stack)

Implementation of stack-based storage allocation for variables and function calls.
